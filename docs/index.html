2. Liên hệ 5 đặc tính điện toán đám mây của NIST

STT Đặc tính NIST Thao tác thực hiện và liên hệ
1 On-demand Self-service
(Tự phục vụ theo yêu cầu)		 Tự tạo Codespace trên GitHub bằng chức năng Create codespace on main, không cần yêu cầu người quản trị cấp phát máy chủ thủ công.
2 Broad Network Access
(Truy cập mạng rộng)		 Chạy Hello Cloud API trên cổng 3000. Chuyển Port Visibility sang Public để truy cập API qua URL HTTPS bằng thiết bị khác, sau đó chuyển lại Private.
3 Resource Pooling
(Gộp tài nguyên)		 Sử dụng CPU, RAM và môi trường Linux do hạ tầng đám mây cung cấp. API ghi nhận host codespaces-824b46, 2 CPU và 7,8 GB RAM. Đây là quan sát về tài nguyên được cấp phát; cơ chế chia sẻ tài nguyên vật lý thuộc phía nhà cung cấp.
4 Rapid Elasticity
(Co giãn nhanh)		 Codespaces hỗ trợ lựa chọn và thay đổi cấu hình máy ảo theo nhu cầu. Trong bài thực hành đã cấp phát môi trường để chạy ứng dụng. Chưa thực nghiệm thay đổi số CPU/RAM, nên chưa trực tiếp kiểm chứng tốc độ co giãn.
5 Measured Service
(Dịch vụ đo lường được)		 Mở GitHub Settings - Billing and licensing - Usage để kiểm tra mức sử dụng. Tài khoản ghi nhận $0.18, được bao gồm trong hạn mức miễn phí, nên số tiền phải trả là $0.00.
